# Try OpenDeepL in about 5 minutes

This is a short **hands-on checklist**, not a speed or quality benchmark. Allow extra time for the first model download, SHA-256 check, and first model load. The 0.7.0 packages target **Apple Silicon Mac** and **Windows x64**; the interface is primarily Chinese. See [installation and first-open guidance](INSTALL.md) before starting.

1. **Install and set up.** Download the [0.7.0 Mac DMG or Windows installer](https://github.com/HHHHHarris/OpenDeepL-updates/releases/tag/v0.7.0) and compare its SHA-256 with the release checksum file. Open the full app and follow setup to download the default **7B Q8 model** (about 8 GB), or verify/import the exact existing file. **1.8B Q8** (about 1.9 GB) is optional fast mode. The runtime is bundled; model weights are not. Mac has no Apple Developer ID signature or notarization, and Windows is unsigned, so first-open warnings or device-policy blocks are possible. Do not disable device protections to run this trial.
2. **Translate synthetic text in the app.** Paste this invented sentence into text translation: `The sample costs $19.50, not $91.50, and weighs 2.5 kg, not 25 kg. Do not ship before Friday.` Translate with 7B. Check that the two amounts, negations, decimals, and `kg` units retain their meaning; wording need not match exactly. If you installed 1.8B, try fast mode and **用 7B 重译** (retranslate with 7B). Note whether the result is correct, incorrect, or you did not test it.
3. **Check ordinary copy first.** In another app, select the same invented sentence, press `⌘C` (Mac) or `Ctrl+C` (Windows) **once**, then paste elsewhere. It should remain an ordinary copy, without an unintended translation trigger. If you want to try double-copy, enable/check that integration in OpenDeepL, grant only the OS permission it requests, and select/copy the sentence twice (`⌘C+C` / `Ctrl+C+C`). Platform permissions and integration availability vary; report a blocked or untested attempt as such, rather than treating it as a text-translation failure.
4. **Observe idle unloading.** After a translation finishes, leave the app idle for at least **60 seconds**. If the app exposes a model-status indication, note whether the loaded model becomes unloaded. If there is no clear indication, mark this **not observed**; do not infer unloading from a quiet UI. Translate again to check that the model can reload.

Optional document trial: use only a throwaway DOCX/PPTX or simple text PDF containing the invented sentence. Documents use **7B**, including when fast mode is selected. PDF translation covers a conservative subset of common horizontal text; scans and complex layouts can be rejected. Keep the original and review the output. See [document limitations](INSTALL.md#documents-and-troubleshooting).

**Share first-run feedback:** choose **First-run feedback** from [New issue](https://github.com/HHHHHarris/OpenDeepL-updates/issues/new/choose). Mark each check **Success / Not tested / Problem**; a blocked install is useful feedback too. GitHub issues are public. Do not post source text from real work, user documents, personal screenshots, secrets, or raw logs; the invented sentence above is enough. Report security concerns via [SECURITY.md](../SECURITY.md), not a public issue.
