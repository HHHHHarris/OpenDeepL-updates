# Try OpenDeepL in about five minutes

This is a **hands-on checklist**, not a speed or translation-quality benchmark. Allow extra time for the first model download, SHA-256 check and first model load. **0.7.1 is a release candidate, not yet published**; use the [latest published release](https://github.com/HHHHHarris/OpenDeepL-updates/releases/latest) until its full packages and checksum file appear. The built package targets are Apple Silicon Mac and Windows x64.

1. **Install and choose your interface.** Verify the published package digest, open the full app, then choose **English** or **简体中文** in Settings. The preference should persist after restarting. App-owned native menus and dialogs need the full 0.7.1 package; OS-supplied buttons may still follow the OS language. The bundled runtime needs a separate default **7B Q8** model (about 8 GB); optional fast **1.8B Q8** is about 1.9 GB. Download or verify/import the exact file. Mac lacks Developer ID/notarization; Windows is unsigned. First-open warnings and device-policy blocks are possible. See [installation guidance](INSTALL.md).
2. **Translate invented text.** Paste this fictional guide into the app, select **English → French**, and use 7B: `At the observatory's open evening, visitors can borrow a sky map. The telescope is on the roof, but the exhibition is on the ground floor. If clouds cover the sky, the talk will continue indoors. This is an invented visitor guide.` Check roof versus ground floor and whether the cloudy-day talk remains indoors. Report the actual output, including any mistake; wording need not match one reference translation.
3. **Try a technical instruction.** Select **Chinese → English** and paste: `这是一段虚构的接口说明。缓存未命中时，不应阻塞主线程。最多重试三次，间隔依次为200毫秒、400毫秒和800毫秒。每次重试必须沿用同一个请求ID。如果用户取消操作，应丢弃尚未完成的响应并释放缓冲区。` Check the negation, three retries, 200/400/800 ms, same request ID and cancellation behavior. If 1.8B is installed, compare fast mode with **Retranslate with 7B**. Earlier synthetic testing found a missed negation in 1.8B; 7B is not guaranteed correct.
4. **Check the desktop entry and idle state.** In another app, select the invented guide. Copy once and paste elsewhere: ordinary copy should remain ordinary. If you choose to test double-copy, grant only the requested feature-specific OS permission and try `⌘C+C` / `Ctrl+C+C`. Integration and permission behavior differ by platform. After translation, leave the app idle for at least **60 seconds**; mark model unloading as observed only if a status indicator shows it. Translate again to check reload.

Optional: try a throwaway DOCX/PPTX or simple text PDF containing invented text. Documents use **7B** even if fast mode is selected. Supported PDF processing is conservative: scans and complex layouts can be rejected. Keep the original and review the saved output.

[Share first-run feedback](https://github.com/HHHHHarris/OpenDeepL-updates/issues/new?template=first-run-feedback.yml): mark each step Success / Not tested / Problem. A blocked first open is useful evidence. GitHub issues are public; include only synthetic text and sanitized observations, not private documents, personal screenshots, secrets or raw logs. Send security issues via [SECURITY.md](../SECURITY.md).
