# 约 5 分钟试用 OpenDeepL

这是一份**动手清单**，不是速度或质量基准测试。首次下载模型、SHA-256 校验和首次加载所需时间另计。0.7.0 安装包面向 **Apple Silicon Mac** 和 **Windows x64**；界面目前以中文为主。开始前请阅读[安装与首次打开说明](INSTALL.md)。

1. **安装与配置。** 从 [0.7.0 发布页](https://github.com/HHHHHarris/OpenDeepL-updates/releases/tag/v0.7.0)下载 Mac DMG 或 Windows 安装程序，对照发布页校验文件核对 SHA-256。打开完整 App，按引导下载默认 **7B Q8 模型**（约 8 GB），或校验并导入已有的完全相同模型文件。**1.8B Q8**（约 1.9 GB）是可选快速模式。安装包自带运行环境，但不包含模型权重。Mac 未使用 Apple Developer ID 签名或公证，Windows 未签名；首次打开可能出现提示，也可能受设备策略阻止。试用时不要关闭设备保护措施。
2. **在应用内翻译合成文本。** 粘贴这句虚构示例：`The sample costs $19.50, not $91.50, and weighs 2.5 kg, not 25 kg. Do not ship before Friday.` 用 7B 翻译，检查两组金额、否定关系、小数点和 `kg` 单位是否保留原意；措辞不必逐字相同。如果安装了 1.8B，再试快速模式和 **用 7B 重译**。分别记录正确、有问题或未测试。
3. **先检查普通复制。** 在其他应用中选中同一句示例，只按**一次** `⌘C`（Mac）或 `Ctrl+C`（Windows），再粘贴到别处；应仍是正常复制，不应误触翻译。想试双复制时，再到 OpenDeepL 检查或启用该入口，仅授予它实际请求的系统权限，然后选中文本连续复制两次（`⌘C+C` / `Ctrl+C+C`）。系统权限及入口可用性因平台而异；受阻或未测请如实标记，不要与应用内文本翻译混为一项。
4. **观察空闲卸载。** 翻译结束后，让应用空闲至少 **60 秒**。如果界面提供模型状态，观察已加载模型是否变为未加载。若没有明确状态，就记作**未观察到**，不要仅凭界面安静推断已经卸载。再翻译一次，确认模型可重新加载。

可选文档试用：仅使用含上述虚构句子的临时 DOCX/PPTX 或简单文字型 PDF。文档路径使用 **7B**，即使选了快速模式也是如此。PDF 只支持常见水平文字的保守子集，扫描件和复杂版式可能被拒绝；保留原件并核对结果。详见[文档限制](INSTALL.md#documents-and-troubleshooting)。
